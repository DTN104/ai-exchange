# Synthetic scenarios

Scenario loading belongs to milestone D and is not implemented yet. This directory currently contains documentation only.

The planned scenario format will version initial cash/inventory endowments, synthetic symbol AIX, initial reference price, trader archetype parameters, delays and resource limits. A run manifest will capture the resolved configuration and master seed so experiments can be reproduced with the same engine and PRNG versions.

Do not add real exchange data or placeholder JSON that the application cannot load. See the approved design before defining the schema.
